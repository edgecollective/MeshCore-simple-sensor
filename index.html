MeshCore — simple sensor kit

Edgecollective's fork of MeshCore, focused on a small sensor kit: a Rook (nRF52840) that reads a MaxBotix ultrasonic distance sensor and transmits LoRa messages to a Heltec (ESP32-S3) receiver, which forwards each reading to a Bayou feed over WiFi.

Offerings

Bayou tutorial →

How the receiver POSTs to Bayou, which fields Bayou recognizes, and a runnable Python script that mimics the sensor.

Setup page →

Browser-based flasher and configuration walkthrough for the sender + receiver pair (uses Web Serial in Chrome/Edge).

Firmware source →

examples/v3-ultrasonic/ — the sender and companion-sensor-receiver source that this kit ships.

Firmware snapshots →

Dated build snapshots (.uf2 / .bin) with README provenance, for reproducing what's currently deployed.

About the upstream

The bulk of this repository is upstream MeshCore, unmodified — its docs, examples, and variants are all still here. The edgecollective-specific additions are the v3-ultrasonic example pair, the Rook variant tuning in variants/rook/, and the dated snapshot directories in firmware/. For general MeshCore documentation see docs.meshcore.io.
